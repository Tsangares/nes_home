# Images

Build and demo photos for the SNES Jr Smart Remote. Drop image files in this
folder and reference them from the top-level `README.md`.

Suggested shots:

- `controller-tap.jpg` — the solder/clip points on the controller cable or PCB
- `divider-board.jpg` — the 1 kΩ / 2 kΩ voltage-divider board
- `pi-in-shell.jpg` — the Pi Zero W mounted inside the SNES Jr shell
- `assembled.jpg` — the finished unit next to the TV
- `demo.gif` — a button press toggling a light / navigating the TV
